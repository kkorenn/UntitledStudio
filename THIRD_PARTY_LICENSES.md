network; Untitled Studio is a desktop app and offers its full source anyway).

require shipping object files so users can relink a modified SoundTouch. Untitled Studio is GPLv3
and ships its complete source code, which already lets anyone rebuild it with a modified
SoundTouch, so the LGPL-2.1-or-later terms are satisfied (LGPL code may be used in GPLv3 programs).

## Not bundled

- **LAME** (MP3 export) is an external command-line program the user installs separately
  (for example `brew install lame`); Untitled Studio only runs it, nothing of it is shipped.
- **Fonts**: none are bundled; the app uses the operating system's fonts.
- **Drum samples and presets** are generated by Untitled Studio itself at first launch.
- **ASIO** (Windows, optional) needs Steinberg's SDK, which we don't ship; see BUILDING.md.
